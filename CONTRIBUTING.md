# Contributing to gentle-emote

Only the maintainer, [efolchmontiel](https://github.com/efolchmontiel), can merge into `main`.

## 1. Open an issue

Use a template. Describe the problem before the change. The issue needs one classification label: `bug`, `enhancement`, `documentation`, `performance`, `refactor`, or `security`.

## 2. Wait for approval

Do not open a pull request until the maintainer adds the `approved` label. An open issue without that label cannot be merged.

## 3. Open the pull request

- Branch name: `type/short-description`, for example `fix/talk-timing`.
- The body must contain a closing reference to the approved issue: `Closes #123`.
- The issue has to be open, in this repository, and classified.
- The pull request needs an approving review.

`main` rejects direct pushes from anyone except the maintainer, and it rejects a merge while the linked-issue check or the review is missing.
